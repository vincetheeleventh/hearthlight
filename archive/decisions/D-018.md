# D-018 · Stage-A prompts compile from visible production objects

**Date:** 2026-08-04 · **Source:** Vince, approved implementation plan · **Agent:** chatgpt

**Context:** Verbatim `Still (frame one)` extraction stopped motion leakage, but it made the workbook
cell both creative direction and provider prompt. Partial-body shots still inherited complete person
descriptions, while changes to meaning, staging, and framing had no durable directing surface.

**Reason:** A still prompt must describe the one visible tableau, not everything known about the scene
or person. Stable Shot Vision revisions preserve Vince's direction. Storyboard, beat, character,
setting, and prop sources provide evidence. A structured production object makes visibility, ownership,
crop, contradictions, and provenance testable before concise provider prose exists.

**Consequences:** Studio Shot Vision is the live creative authority. The workbook remains an
import/export baseline with exact provenance. A tool-restricted worker returns strict per-shot JSON;
a deterministic renderer produces the Krea prompt. Character traits are region-tagged and included
only when visible. Action remains validation context only. Prompts are immutable outputs, never
authority. Prompt Board approval binds the exact batch fingerprint and cost ceiling before the durable
Krea runner may spend. D-016's frame-one and no-motion protections remain, but its verbatim-cell rule
is superseded.
